Dátové zdroje — adaptéry

  • BTS prílety: bts.aero · AeroDataBox API · FlightAware AeroAPI — adaptér v dashboard.js → fetchFlights()
  • Hlavná stanica / Petržalka: ZSSK CIS open data (cestovný poriadok) → fetchTrainArrivals()
  • AS Nivy: Slovak Lines / RegioJet / FlixBus CSV cestovných poriadkov → fetchBusArrivals()
  • Eventy: Goout.net, Predpredaj.sk, Ticketportal, kalendár NR SR, Slovan/Tipos Aréna kalendár → fetchEvents()
  • Konkurencia: Booking/Airbnb scraping (cez tvoj server alebo služby ako AirDNA/PriceLabs) → fetchCompetitors()

Bez backendu (GitHub Pages) bežia tieto adaptéry v simulačnom režime so seedovanými dátami. Keď zoženieš API kľúče / proxy, prepneš zdroj v dashboard.js.
